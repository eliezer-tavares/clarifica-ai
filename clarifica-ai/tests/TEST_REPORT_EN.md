## Defects and decisions of this revision

1. **Memory peak with 6 resident models (found by the battery):** the validation machine has 4 GB — the full suite in ONE process brought Node down when loading the 6th model (QA) with the others resident. **Structural fix:** the v2.0.0 inferences live in `ai-worker-lingua.test.js`, a dedicated process — the peak is distributed across `npm test` runs, the original file keeps the 5 v1.4.0 models and the full battery now runs green on 4 GB with `--test-concurrency=1` (guidance already documented in the README since v1.3.0). Decision documented as a pattern: **new models = new inference file**.
2. **URL collision on the E2E "active tab" (inherited from v1.4.0, now visible):** `abrirPaginaDeTeste` resolves the tab by URL — with TWO pages sharing the same URL (the beforeAll one and the new one), the injection goes to the first. The clean-page panel test now uses a unique URL (`/artigo-limpo`, an unmapped route the server answers with the article). Pattern noted for new tests: **every test that inspects the target page's DOM uses its own URL**.
3. **External panel closing (Esc) does not change the popup:** by design — the popup is ephemeral and the closing is ANNOUNCED on the page (aria-live region), the same contract as externally terminated captions. The next click on the popup button reopens normally (the host state on the page is the source of truth). The test validates the announcement on the page, not the popup status.
4. **`deepEqual` with objects from other realms:** objects created inside jsdom/window.eval carry prototypes from another world — Node's `deepStrictEqual` fails even with identical content. The new suites compare via JSON deserialization (`doReinoNode`) or field by field. Documented pattern.

## Scope and limitations of this battery

- **Live-captions manual script** remains optional (real tab capture is not reliable in headless — full script at revision 9, repeatable on every machine before publishing).
- **Extractive QA is English-only by model** (SQuAD): English pages get the best answers; Portuguese pages receive less reliable excerpts — limitation declared in the README and in the release-notes panel.
- **Model-assisted Plain-Language Portuguese** does not replace human review (generation with simplicity parameters + neural translation).
- **Firefox:** structural validation by test (MV2 manifest, hiding of controls); execution with a real Firefox browser remains a manual script (the suite's Playwright validates Chromium loading the extension).
- **Real inference:** the 6 models ran with the pinned-revision weights from the local cache; on the first run on a new machine the download is ~865 MB (`npm run preparar:modelos` pre-downloads).
