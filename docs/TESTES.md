## Como executar

```bash
cd clarifica-ai/tests
npm install
npm test            # suíte unitária completa (inclui inferência de IA real)
npm run test:e2e    # extensão no Chromium real via Playwright
```

> **Pré-requisitos:** os testes E2E exigem o navegador do Playwright — instale uma vez com `npx playwright install chromium`. **Inferência real:** os testes de IA executam os modelos de verdade — na primeira execução em uma máquina nova os pesos (~865 MB) são baixados do Hugging Face para `clarifica-ai/tests/.cache`. Para pré-baixar antes: `npm run preparar:modelos`. **Máquinas com menos de ~6 GB de RAM:** executar com `npm test -- --test-concurrency=1` (os modelos residentes de cada arquivo de inferência elevam o pico de memória; as inferências da v2.0.0 vivem em processo próprio — `ai-worker-lingua.test.js` — para distribuir o pico). **IA real dentro do navegador (opt-in):** `CLARIFICA_E2E_IA=1 npm run test:e2e`. **Firefox:** validação estrutural por teste; execução manual descrita em [`FIREFOX.md`](FIREFOX.md).
