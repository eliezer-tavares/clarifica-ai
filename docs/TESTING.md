## How to run

```bash
cd clarifica-ai/tests
npm install
npm test            # full unit suite (includes real AI inference)
npm run test:e2e    # extension on a real Chromium via Playwright
```

> **Prerequisites:** the E2E tests require the Playwright browser — install it once with `npx playwright install chromium`. **Real inference:** the AI tests run the real models — on the first run on a new machine the weights (~865 MB) are downloaded from Hugging Face to `clarifica-ai/tests/.cache`. To pre-download: `npm run preparar:modelos`. **Machines with less than ~6 GB of RAM:** run with `npm test -- --test-concurrency=1` (each inference file keeps its models resident; the v2.0.0 real-inference tests live in their own process — `ai-worker-lingua.test.js` — to spread the peak). **Real AI inside the browser (opt-in):** `CLARIFICA_E2E_IA=1 npm run test:e2e`. **Firefox:** structural validation by tests; manual execution described in [`FIREFOX.md`](FIREFOX.md).
